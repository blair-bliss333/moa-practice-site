# MOA website: practice copy

This is the practice copy of the new MOA website for your two-week trial. Nothing you do here touches moaonline.org, so try anything.

Open this folder in the Code tab of the Claude desktop app and start with: "Give me a quick tour of how this site is organized, in plain English." Your training guide has the rest.

If anything ever asks you for a password, stop and message Blair.

Every update you send for review gets its own preview link from Netlify, posted on the update's page on GitHub. Nothing goes live until it's approved.
